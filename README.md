# Шкали інсультного відділення

Робочий інструмент для інсультного відділення КНП «Дубенська міська лікарня»: NIHSS, ШКГ, FOUR, mRS, GUSS, ТЛТ (час і терапевтичне вікно, калькулятор альтеплази), «Клінічне рішення лікаря», друк бланків A4 / PDF. Орієнтовано на наказ МОЗ № 1070.

**Відкрити:** https://stk92-ua.github.io/shkaly/

- Дані пацієнтів зберігаються **лише на пристрої** користувача (у браузері). У цьому сховищі є тільки код додатка, жодних даних пацієнтів.
- Додати на головний екран: Android — Chrome → ⋮ → «Додати на головний екран»; iPhone — Safari → «Поділитися» → «На екран «Додому»».
- Інструмент допомагає в розрахунках і оформленні; клінічне рішення ухвалює лікар.

## Як випускати оновлення
1. Внести зміни в `index.html`.
2. Збільшити `APP_VER` та `APP_NOTES` в `index.html` і так само `v`/`notes` у `web-version.json` (формат `РРРР.ММ.ДД.N`).
3. Кнопка «⟳ Оновити й перезавантажити» внизу сторінки перевіряє версію, зберігає дані й перезавантажує, повертаючи відкритого пацієнта.
4. Закомітити в `main` — сайт і Android-застосунок покажуть користувачам вікно «Доступне оновлення» з інструкцією, а після оновлення — «Що нового».
